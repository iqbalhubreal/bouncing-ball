# Bouncing Ball Studio

This project is the original single-page app separated into independent HTML, CSS, and JavaScript files.

## Files

- `index.html`: page structure and app markup
- `css/styles.css`: page styling
- `js/app.js`: application logic

## Run

Open `index.html` in a modern browser. Keep the folder structure intact.

Audio playback and processing use the browser Web Audio API. Your browser may require a user click before audio can start.
